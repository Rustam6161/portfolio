# Салимбаев Рустам — портфолио сайты

Болгону HTML, CSS жана vanilla JavaScript. Framework, backend жана куруу куралдары жок.

## Ишке киргизүү
1. Папканы каалаган жерге көчүрүңүз.
2. `index.html` файлын браузерде ачыңыз. Сервер талап кылынбайт.

## Түзүмү
- `index.html`, `about.html`, `skills.html`, `contact.html` — барактар
- `css/style.css` — стилдер
- `js/script.js` — меню, аватар резерви, форма
- `assets/avatar.svg` — нейтралдуу аватар (өз сүрөтүңүздү ушул атта алмаштырсаңыз болот)

## Эскертүү
Байланыш формасы — frontend үлгүсү, маалымат эч жакка жөнөтүлбөйт.
